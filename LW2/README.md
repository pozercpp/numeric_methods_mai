# Лабораторная работа 2, вариант 26

## Исходные данные

- 2.1: `lg(x + 1) - x + 0.5 = 0`.
- 2.2 (`a = 2`): `2x² - y + y² - 2 = 0`, `x - sqrt(y + 2) + 1 = 0`.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/task_2_1
./build/task_2_2
```

Обе программы запрашивают точность `eps`. Например: `1e-8`.

В таблицах выводятся приближения, величина шага, невязка и фактическая
погрешность относительно корня, вычисленного методом Ньютона с повышенной
точностью. Эти данные позволяют проанализировать зависимость погрешности от
номера итерации и сравнить скорость сходимости методов.
